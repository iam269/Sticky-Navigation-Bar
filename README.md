# Sticky Navigation Bar 🌟

A responsive sticky navigation bar project built with HTML, CSS, and JavaScript (jQuery). This web component features a sleek design that changes appearance on scroll and includes mobile-friendly responsive behavior.

## Features ✨

- **Sticky Navigation**: The nav bar sticks to the top of the page as you scroll 📌
- **Scroll Effects**: Background and logo size change dynamically when scrolling 🔄
- **Responsive Design**: Adapts to mobile devices with a hamburger menu 📱
- **Smooth Transitions**: CSS transitions for a polished user experience 🎨
- **jQuery Integration**: Uses jQuery for interactive scroll and menu toggle functionality ⚙️

## Technologies Used 🛠️

- **HTML5**: Semantic markup for structure 📄
- **CSS3**: Styling with transitions and media queries 🎨
- **JavaScript (jQuery)**: Interactive functionality 🔧
- **Font Awesome**: Icons for enhanced UI 🎯

## How It Works 🔍

- On desktop: Full navigation bar with logo and menu items
- On scroll: Background becomes semi-transparent and logo shrinks
- On mobile: Hamburger menu toggles the navigation list
- Responsive breakpoints at 768px for mobile optimization 📏
